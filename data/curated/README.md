# 真实资料待整理

这里已有罗技中国官网的小样本真实采集草稿，位于 `crawl-runs/`，每批保留 `candidates.json` 和 `report.json`。网站默认通过只读接口展示最新批的待审核资料；这些样本尚未入库成为可推荐商品。演示推荐入口继续使用 `data/demo/catalog.json` 的虚构资料。

2026-10-02 测试采集两个具体版本：Pebble Keys 2 K380s 白色美国英语 QWERTY（920-011731）、M240 轻音蓝牙鼠标玫瑰粉（910-007124）。参数来自官网页面的 JSON-LD 和公开内嵌参数。重量、尺寸等资料按产品家族范围记录，不自动推断电池重量口径；官网宣称的静音不转换成已实测标记。

两页商品家族价格数据均为 0，草稿保存 `price_minor: null` 并标记无可用版本报价。这些字段不代表免费商品，也不代表已确认库存。完整过程见 `evaluations/CRAWL_REPORT.md`。

每条真实资料至少需要：稳定版本 ID、品类与版本名称、参数的来源 URL 和核对时间、公开价格的金额/币种/渠道/适用条件/采集时间、库存状态，以及每条静音/重量/用途结论的证据与适用范围。缺少的数据保留未知，不用宣传词补齐。

已提供独立的低频公开页面采集脚本，但草稿 → 人工核对 → 发布的导入流程仍待建立。当前适配器只针对罗技中国官网的指定公开商品页面，不是任意网站通用爬虫；尚未采集到可用的人民币市场价格，也没有设置自动定时更新。

正式资料管理、独立证据表和发布版本尚待实现，不能将 `mode` 改为真实就当成可上线资料。
