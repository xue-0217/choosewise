# 择物 · 首版视觉与交互

“择物 / CHOOSEWISE”为工作名称，可随品牌决策调整。

使用本地 Skill「极简界面设计」与「完整代码输出」。界面采用暖白底、鼠尾草绿提示、深灰主按钮；平面边框与少量留白，帮助用户理解预算、条件和方案差异。中文字体优先系统苹方/微软雅黑，不依赖远程字体服务。

桌面采用需求表单与推荐区双栏，手机改为顺序单栏。初始不预选品类；用途为可修改的初始选项，推荐前始终展示确认摘要。数字区、连接方式与声音条件可直接选择，文本冲突回到表单修改。

右侧按状态切换：说明 → 整理中 → 需求确认 → 推荐结果或无匹配。结果支持方案切换、横向参数比较、资料依据与知识侧栏。修改表单不会立即调用服务，完成的新结果才替换上一份结果。

键盘与鼠标插图为程序绘制的结构示意，界面明确显示“外观示意”。型号、价格和轻声标记属于虚构演示数据。界面不展示购买按钮或暗示真实商品实测。

提供键盘焦点、侧栏焦点约束与 Escape 关闭；尊重系统减少动画设置。技术实现见 `apps/web/src/`，视觉截图与验收记录见 `evaluations/`。
