## 当前限制和下一步

- 需求文本仅有限关键词整理，无法保证理解所有否定句、接口兼容性、手型、轴体、重量阈值或复合要求。重要条件请使用明确选项并检查确认摘要。
- 真实资料与证据体系、价格更新、商品参数来源、审核导入、按需知识检索尚未实现。当前知识侧栏只读取三篇编辑规则，演示依据来自同一虚构 JSON，不能视作独立评测。
- 模型适配代码尚未联调，没有配置供应商与密钥，没有付费请求；真实模式暂时拒绝启动。模型输出的语义与证据一致性需要后续专门校验。
- API 是单进程演示执行器。重启会将未完成任务标记失败，而不会自动恢复执行；取消会阻止后续结果发布，尚未验证外部模型的传输取消。并发数据库锁、心跳、持久化 Worker、数据清理与正式限流尚待补齐。
- 本机 Docker 引擎未启动；PostgreSQL、镜像构建和容器健康检查未做运行验收。当前使用本地 SQLite。未部署公网，未加入商城、账号、订单或支付。
- pytest 有一条 Starlette 对 httpx 测试客户端的弃用提示，未影响 14 项测试；后续升级测试传输层时处理。浏览器运行有终端颜色变量提示，未产生页面错误。

下一步先人工整理并核对首批真实商品版本和证据，完成审核发布链路，再接入选定模型并用真实样本评测推荐准确性。

## 单品插图修复与真实资料页面接入

日期：2026-10-02。此节为最新状态，前文的仅演示页面记录属于先前阶段。

用户截图中，单独推荐键盘时 SVG 跟随整张卡片变宽，自动高度随 viewBox 比例增大，超出 140px 插图容器并盖住型号/参数。现在明确设置插图宽度上限、相对容器高度与旋转范围，并约束容器溢出；插图实际边界位于容器内，不靠裁剪掩盖巨大 SVG。

网站默认「真实资料」，展示 K380s 与 M240 的官网样本、具体 SKU、采集日期和来源链接。数据缺少有效价格或审核时，真实请求返回 `insufficient_evidence`，没有推荐方案，不调用演示筛选。虚拟型号只在用户主动选择「演示体验」后出现；旧演示快照在刷新后的默认真实资料模式中隐藏，并可通过演示入口恢复。
